# 可选软件领域风险提示

按实际风险选读，不是所有项目的强制阶段。先使用通用路线，只把改变行为、契约或验收的风险带入准备包，复用未失效证据。没有专业责任人或实测证据时保留未知，不宣称模板证明合规。

| 场景 | 按需补充 | 可观察验收方向 |
| --- | --- | --- |
| CLI / 批处理 | 退出码、编码、空输入、重跑、部分失败、文件覆盖 | 字节、退出码、重跑结果和恢复位置 |
| Web / API | 身份/租户、分页、新鲜度、错误/空值、幂等、兼容 | 权限与契约样例、失败与重试、数据一致性 |
| 移动端 / 离线同步 | 真相归属、冲突、断网重试、进程终止、迁移 | 离线操作、恢复联网、冲突与重启 |
| 嵌入式 / 硬件 | 板型、资源预算、时序、掉电、协议版本、写入权限 | 构建和实机分别记录；模拟不替代设备结果 |
| 游戏 / 编辑器扩展 | 资源/序列化兼容、场景生命周期、撤销/保存、编辑器边界 | 代表性场景、旧资源读取、保存与运行 |
| 数据 / AI | 数据许可、划分与泄漏、质量指标、未知精度、成本、漂移 | 独立数据集、失败样本、成本与延迟；无证据不承诺精度 |

选择移动端不等于必须生成云服务；选择嵌入式也不授权刷设备。必要探索写成有范围、停止条件和验收证据的任务，执行仍需对应授权。
