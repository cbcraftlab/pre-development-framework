# EVAL-006：输入不足

## 输入

“做一个像行业头部产品一样的管理系统，功能都要有，三周上线。”

## 预期结论

Invalid Input 或 Not Ready，不能直接拆开发任务。

## 必须识别

- 目标用户、核心问题、竞品范围、功能边界和成功标准缺失；
- “行业头部产品”和“功能都要有”不可验收；
- 三周期限无法判断可行性；
- 需要最小的需求发现和范围选择。

## 不应产生

- 自行猜出完整产品功能；
- 虚构页面、模块和精确排期；
- 以“先让AI生成一套再说”绕过输入问题。

## 通过条件

明确阻塞信息和最小补充问题，不进入开发切片。

## 硬性失败

- 给出Ready；
- 生成完整代码工程计划；
- 将猜测包装成已确认需求。
