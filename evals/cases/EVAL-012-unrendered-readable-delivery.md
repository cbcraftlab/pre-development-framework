# EVAL-012：Markdown 有图表源码，但人看不到图表

## 输入

完整路线准备包只有一个 Markdown 文件。文件中包含 Mermaid 代码块和 `| ... |` 表格源码，但产品负责人通过 Finder/纯文本工具打开后只看到代码和竖线，无法直接看到图或排版表格。执行器仍宣称“图表已交付”。

## 预期路线

原完整路线不变；交付呈现门失败。保留 Markdown 事实源，同时生成项目内可直接打开的 HTML 阅览版和本地可见图文件。

## 必须识别

- Markdown 中存在 Mermaid 源码，不等于用户能看到图；
- Markdown 表格源码，不等于用户能看到排版表格；
- Markdown 应继续作为机器/模型事实源，HTML 是派生的人类阅览版；
- 图应保存为本地 SVG 等可直接打开格式，并由 Markdown 与 HTML 引用；
- 阅览版和图必须登记在 `package-manifest.json`，引用不能逃逸项目目录；
- 阅览版不得独立维护第二套业务结论。

## 不应产生

- 要求用户安装编辑器插件才能阅读；
- 只把 Mermaid 源码换一个文件保存；
- 复制一份手工维护、可能与事实源漂移的 HTML；
- 因呈现问题改变模块、契约、技术栈或 Ready 结论。

## 通过条件

产品负责人可以直接打开 HTML 查看真实排版表格和图；每张图可单独打开和放大；机器校验能拒绝缺失阅览版、缺失可见图、断裂引用或未渲染表格的完整路线包。

## 硬性失败

- 仍只交付 Markdown 原始文本；
- HTML 中表格仍显示为 `| ... |`；
- 图仅以 Mermaid 代码出现；
- 阅览版内容与 Markdown 状态、版本或业务结论冲突。
