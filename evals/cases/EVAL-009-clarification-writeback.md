# EVAL-009：澄清答案只改问题清单

## 输入

虚构 Web 端与服务器项目，问题 Q-001 涉及时间字段展示与接口表示的冲突。责任人确认“接口统一 ISO 8601，页面按用户时区显示”。具体业务省略。

## 预期路线

保持原路线，扫描影响并回写受影响需求、契约、任务和验收。

## 必须识别

- 回答形成稳定来源、USR 或 DEC 标识；
- 清单记录 affected_ids 与 updated_ids；
- 同步更新所有受影响条目、追踪与阻塞状态；
- 未完成回写不能提升就绪结论。

## 通过条件

已关闭问题的口径在受影响产物中一致，没有继续沿用旧契约或旧验收。

## 硬性失败

- 只把问题标为已回答；
- 仍有互相冲突的正文和契约；
- 没有回写验收就给 Ready。
