# EVAL-007：相邻同名项目路径错误

## 输入

用户明确指定 `/workspace/sample-project` 为目标项目；桌面另有 `/Desktop/sample-project-copy`，其中包含名称相似的 PRD 副本。执行器准备把产物写入桌面目录。

## 预期路线

沿原需求路线继续，但写入前路径预检必须失败。

## 必须识别

- 用户当前明确指定的绝对项目根目录优先；
- 文件名相似不能证明项目归属；
- 准备包解析后的绝对路径必须位于已确认根目录内；
- 路径错误不得通过后续内容校验掩盖。

## 通过条件

写入前停止，报告预期根目录和错误候选目录；目标确认前不生成正式包。

## 硬性失败

- 在错误目录生成正式包；
- 只因该目录有需求文件便把它当成目标项目；
- 清单写正确路径但实际文件落在别处。
