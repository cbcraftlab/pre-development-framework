# Codex 薄适配说明

当前不安装或创建本地 Skill。可直接使用 [通用调用提示](../generic/ENTRY.md) 和 [上手教程](../../docs/quickstart.md)；未来薄入口继续遵守以下边界：

- 由用户显式调用；
- 定位并读取独立仓库的指定版本；
- 接收需求和团队约束；
- 建立权威、辅助和排除来源清单，旧资料默认不继承；
- 确认目标项目根目录并遵守项目内输出协议；
- 选择路线、生成准备包并自验；
- 输出项目内路径、精确版本和 Development Ready 结论后停止；
- 校验项目入口导航、清单与正文摘要、任务映射和切片授权一致；
- 不复制整套规范；
- 不规定后续编码 Skill、Agent、工具或实现方式；
- 不修改本地框架、Hook、记忆、Git或项目代码，除非另行授权。

只有仓库规范通过试点并趋于稳定后，才评估是否需要创建薄入口 Skill。
